# سایت شخصی کمیل مزرعی

سایت با Jekyll ساخته شده و روی GitHub Pages منتشر می‌شود. طرح از Claude Design آمده است.

## نوشتن پست بدون کدنویسی
- **راه ۱:** متن را در ورد یا گوگل داک بنویسید و در پروژه‌ی Claude بفرستید و بگویید «منتشر کن».
- **راه ۲:** به app.pagescms.org بروید، با حساب گیت‌هاب وارد شوید، این مخزن را انتخاب کنید و در بخش «نوشته‌ها» پست جدید بسازید.

## ساختار
- `_posts/` نوشته‌ها (هر فایل یک پست، نام فایل با تاریخ میلادی شروع می‌شود؛ سایت تاریخ را شمسی نشان می‌دهد)
- `_data/projects.yml` و `_data/resume.yml` محتوای صفحه‌های پروژه‌ها و رزومه
- `_config.yml` نام، ایمیل، تلفن و لینک‌های شبکه‌های اجتماعی
- `assets/css/site.css` رنگ‌ها و قالب
